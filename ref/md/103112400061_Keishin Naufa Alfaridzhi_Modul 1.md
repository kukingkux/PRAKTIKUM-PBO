### **1. JDK dan IDE**

- **JDK**: Java Development Kit (JDK) merupakan sebuah kumpulan software development tools dan library pendukung yang tergabung dalam Java Runtime Environment (JRE) dan Java Virtual Machine (JVM). Ini diperlukan untuk menjalankan program Java.
- **IDE**: Integrated Development Environment (IDE) merupakan software application yang membantu programmer membangun kode software secara efisien.
